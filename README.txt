MYSTIQUE SHADERS WEBSITE
By M123Mc_Op

HOW TO USE
1. Extract the website ZIP.
2. Open index.html in a modern browser to preview it.
3. Upload the complete folder to any static web host (GitHub Pages, Netlify, Cloudflare Pages, etc.).
4. Keep the assets/ and downloads/ folders beside index.html.
